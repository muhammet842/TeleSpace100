# TeleSpace 100

TeleSpace 100 is a retro TeleText-style new tab page.

It uses a black CRT screen, scanlines, pixel colors, and keyboard navigation.

## Pages

- `100` - Main menu
- `200` - NOAA space weather and Kp index
- `300` - NASA astronomy picture of the day

## Controls

Type a three-digit page number with your keyboard.

Examples:

```text
100
200
300
